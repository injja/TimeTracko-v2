<h1>TimeTracko – Time & Project Management Application</h1>

<p>
  TimeTracko is an application designed to help users manage their time and projects,
  both individually and in teams. The project was developed as part of learning
  object-oriented programming in Java and building backend applications using Spring Boot.
</p>

<h2>Main features</h2>
<ul>
  <li>Tracking time spent on tasks and projects</li>
  <li>Managing personal and team-based projects</li>
  <li>Assigning tasks to users</li>
  <li>Monitoring productivity and work progress</li>
</ul>

<h2>Purpose</h2>
<ul>
  <li>Practicing object-oriented programming (OOP) in Java</li>
  <li>Learning backend development with Spring Boot</li>
  <li>Applying clean code and good design practices</li>
  <li>Understanding application structure and modular design</li>
  <li>Learning xternal API integration</li>
  <li>Learning relational database organization and integartion with Spring Boot</li>
</ul>
